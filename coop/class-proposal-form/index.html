Class Proposal Form

This form is for families that are existing members of Koinonia Homeschool Group. If you are not an existing member you can learn how to become one on our About page.

Classes must meet at least one of these general requirements to be offered at Koinonia.

  • The class includes minimal homework
  • The class is an elective / enrichment based class, not a core subject class
  • The class is best accomplished in a group (choir, theater, sports, etc.)
  • The class teaches a skill that many parents may not be able to, or knowledgeable enough to teach at home. 

We have found that the most successful classes are interactive and “hands-on.”
